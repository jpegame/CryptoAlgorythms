Cifra de Hill

A Cifra de Hill é uma cifra de substituição baseada em álgebra linear. A matriz chave K (2×2, números inteiros) multiplica blocos de 2 letras do texto (mod 26). Na decriptação, utiliza-se a matriz inversa K⁻¹.

Criptografia

Apenas letras de A a Z são usadas: espaços, acentos e números são removidos. Se o total de letras for ímpar, a API acrescenta um X.

Matriz 2×2

O determinante da matriz deve ser coprimo de 26 (a API valida).

Decriptação

Deve ter quantidade par de letras. O resultado pode terminar com o X de preenchimento.

Matriz 2×2

Use a mesma matriz da criptografia; a API calcula a inversa.
